# prep-stock-api
An API that can be used to manage restaurant inventory.

## Why this project
In addition to providing a clear overview of inventory levels when managing stock, it also helps develop and improve coding skills.

## Features (planned)
Establish an API for adding, querying, modifying, and deleting data. 
Connect the API to a database, including usage records, stop-loss checkpoints, and material preparation suggestion endpoints.

## Tech stack
Python、FastAPI、PostgreSQL
